Duas horas, zero instalação e o JOIN como linha de chegada. 🗃️

Preparei uma capacitação de MySQL e SQL para a Semana de Engenharia Química da UFRJ (SEQ), em parceria com a for_code. O público é de iniciantes, e a regra é uma só: ninguém perde tempo instalando nada.

🐳 O ambiente roda em contêineres (MySQL 8.4 e phpMyAdmin), com um túnel para os participantes acessarem direto pelo navegador.
⏱️ Dos 120 minutos, cerca de 75 são de prática guiada.
🧭 O caminho: dado e SGBD → tabelas, tipos e chaves → INSERT e SELECT com filtros → UPDATE e DELETE (e o perigo do WHERE esquecido) → chave estrangeira e JOIN.

O material ficou aberto para quem quiser estudar sozinho ou reaplicar:
📘 guia de 40 páginas, com exercícios;
🖥️ slides com notas do apresentador e relógio de cada bloco;
💾 o script da aula, que reconstrói todo o cenário.

⚙️ Tudo é LaTeX, compilado pelo GitHub Actions e publicado automaticamente no GitHub Pages.

👉 Material: andradasdev.github.io/sql
👉 Código: github.com/ronidomingues/mysql-training

## 2. Seção "Projetos" do perfil

**Nome do projeto:** Capacitação de MySQL e SQL

**Associado a:** for_code, liga acadêmica (Diretor de Projetos)

**URL:** https://github.com/ronidomingues/mysql-training

**Descrição:**

Capacitação de 2 horas para iniciantes, feita para a Semana de Engenharia Química da UFRJ (SEQ) em parceria com a for_code. Inclui guia de 40 páginas, slides com notas do apresentador e o script SQL da aula.

• Conteúdo: modelo relacional e SGBD, DDL com tipos e chaves, CRUD, filtros e ordenação, chave estrangeira e JOIN.

• Ambiente sem instalação: MySQL 8.4 e phpMyAdmin em contêineres Docker, acessados pelo navegador através de um túnel. Cerca de 75 dos 120 minutos são de prática.

• Automação: o LaTeX é compilado pelo GitHub Actions e publicado em outro repositório pelo GitHub Pages.

**Competências:** MySQL · SQL · Modelagem de dados · Docker · LaTeX · GitHub Actions · Didática
